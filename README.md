## 🚀 How to Run Locally

```bash
# Step 1 — Clone the repo
git clone https://github.com/sidducv0528/Python-Fundamentals-and-Mini-Projects.git

# Step 2 — Go into the folder
cd Python-Fundamentals-and-Mini-Projects

# Step 3 — Run any project
python mini_projects/beginner_projects/calculator.py
python mini_projects/intermediate_projects/quiz_game.py
python mini_projects/advanced_projects/slot_machine.py
```
